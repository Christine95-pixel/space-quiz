# Project guidance

- Keep the quiz in the root `index.html`, using inline HTML, CSS, and vanilla JavaScript. Preserve the single-file, dependency-free approach; do not add libraries, tooling, or build steps.
- Use semantic HTML and support keyboard interaction and visible focus. Add ARIA only when native semantics are insufficient, and respect reduced-motion preferences.
- When changing quiz behavior or presentation, verify the UI in a browser, including the affected interactions; static inspection alone is not enough.
- Keep changes focused and code readable with descriptive names. Avoid unnecessary comments.
